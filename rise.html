Articulate Rise Projects

These projects showcase my skills in Articulate Rise 360, a responsive, web-based authoring tool for building sleek, user-friendly eLearning experiences. From microlearning modules to integrated scenario-based lessons, each example reflects my ability to apply instructional design principles using Rise’s modular structure, interactive blocks, and clean visual layout. The collection demonstrates how I create learning experiences that are clear, accessible, and optimized for both desktop and mobile learners — all while maintaining engagement and instructional integrity.
