Adaptive Assessments

Audience
Reusable templates that can be adapted for different subjects, difficulty frameworks, and assessment needs. [TODO: add the intended learner audience]
Challenge
Fixed‑path quizzes give every learner the same questions. I wanted assessments that keep learners challenged without overwhelming them, improve engagement, and give richer insight into performance.
My solution

Adaptive assessment templates that deliver a personalized testing experience, adjusting question difficulty in real time to each learner’s demonstrated skill level. I developed two distinct models:

  • Set‑Level Model: adjusts difficulty after every set of three questions, ideal when performance is best measured in short, grouped segments.
  • Question‑Level Model: adjusts difficulty after each individual question, for precise evaluation of a learner’s depth of knowledge for each concept.
Key features / skills shown
  • Instructional design, branching logic, variable tracking, and custom player design
  • Applies Bloom’s Taxonomy, mastery learning, and formative assessment principles
  • Fully customizable templates, easy to adapt for new subjects and difficulty frameworks
