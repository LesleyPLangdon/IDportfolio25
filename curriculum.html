Press Start: Code Your Own Arcade, Block by Block

Audience
Students in grades 4–8 at The Technology Access Project (TAP), a New Jersey nonprofit that teaches coding and robotics to kids.
Challenge
Teach core programming concepts to students in grades 4–8 in a hybrid format, with an assessment approach flexible enough to be ungraded, pass/fail, or a number grade.
My solution

TAP’s flagship course, built on MakeCode Arcade. Each week follows a hybrid rhythm: a live build session of about two hours, a midweek video check‑in, and office hours. Four units build on each other:

  1. Building Blocks: sequencing, events, variables, and player input
  2. Level Up: conditionals, boolean logic, and loops
  3. Power Up: randomness, lists, and functions
  4. Game On: combine the microgames into one arcade collection, with a boss level
Key features / skills shown
  • Scope and sequence: four units that move from sequencing and events to lists and functions
  • Learning progression: each week’s microgame becomes part of the final arcade collection
  • Assessment design: each week’s concept is proved by building a microgame; the course supports ungraded, pass/fail, or number‑grade assessment
  • Hybrid delivery: live build sessions, video check‑ins, and office hours

SMART Goals

Audience
Participants who want to set and achieve personal and professional goals. [TODO: name the specific audience]
Challenge
Give participants the knowledge and skills to define clear, concise, actionable goals, overcome common obstacles, and track their progress, whether they learn live or on their own schedule.
My solution
An interactive course built on the SMART framework (Specific, Measurable, Achievable, Relevant, Time‑Bound). Participants learn to define goals, identify and overcome common obstacles, develop action plans, and track their progress toward success. The course comes in three formats: a Canva presentation for synchronous delivery, a Canvas course for asynchronous learners, and a PowerPoint version.
Key features / skills shown
  • Blended design: one course, delivered both synchronously and asynchronously
  • LMS course build in Canvas
  • Goal‑setting, action planning, and progress tracking

Canva, Canvas LMS, PowerPoint
